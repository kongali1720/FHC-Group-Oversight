# Templates Index

Place reusable, blank templates here. Do not commit completed templates containing confidential information.

Suggested templates:
- Investment memorandum
- Due-diligence checklist
- Budget and forecast
- Monthly finance report
- Bank reconciliation
- Risk register
- Management dashboard
- Investment committee decision record

Each template should state its owner, version, intended use, required approvals, and review date. Examples should use synthetic data.
