# Pengelolaan Dokumen dan Hak Akses

## Klasifikasi
- **PUBLIC:** materi yang memang boleh dipublikasikan.
- **INTERNAL:** prosedur umum dan laporan agregat non-rahasia.
- **CONFIDENTIAL:** laporan keuangan internal, anggaran, kontrak, dan data vendor.
- **RESTRICTED:** data rekening, identitas/KYC, payroll, data investor, dokumen legal rahasia, kredensial, dan informasi sensitif lainnya.

## Penyimpanan
- Repository GitHub hanya untuk kebijakan/template yang aman dipublikasikan atau repository privat dengan akses yang disetujui.
- Dokumen CONFIDENTIAL/RESTRICTED harus disimpan di penyimpanan perusahaan dengan akses berbasis peran, MFA, log akses, dan retensi yang ditetapkan.
- Jangan commit file `.env`, token, password, OTP, private key, rekening lengkap, KYC, payroll, atau dokumen investor rahasia.
- Gunakan placeholder pada contoh dan template.
- Review akses ketika karyawan pindah jabatan atau keluar.

## Versi dan retensi
Setiap kebijakan memuat pemilik, nomor versi, status draft/final, tanggal berlaku, approver, dan tanggal review berikutnya. Retensi dan pemusnahan dokumen mengikuti kebijakan perusahaan serta ketentuan hukum yang berlaku.
