# Documentation Index

Use this directory for maintained project documentation.

Suggested sections:
- `governance/` — governance principles, approval authority, and decision logs
- `organization/` — organization diagrams and role descriptions
- `investment-policy/` — investment screening and monitoring procedures
- `finance-operations/` — month-end close, reconciliation, and reporting procedures
- `trading-controls/` — trading mandate, exposure limits, and settlement controls
- `it-security/` — access management, backup, and incident-response standards
- `implementation-roadmap/` — milestones, owners, dependencies, and status

Only mark a policy as approved when the authorized company decision-maker has formally approved it. Do not store confidential source records in this public documentation repository.
